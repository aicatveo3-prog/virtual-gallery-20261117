# 작품 속으로 갤러리 (가상 갤러리 플랫폼 프로토타입)

브라우저에서 걸어 다니며 작품을 보고, 작품에서 파생된 3D 공간으로 들어가 보는 가상 갤러리 프로토타입입니다.

- 메인 갤러리 1F 기획전: 호랑이 그림 속 대숲(거대한 호랑이), 청자 매병 안쪽 공간
- 2F 작가 개인전: 작품의 색으로 자동 생성되는 3D 공간
- 3F 입점 작가 모집 (빈 전시실)
- 상설관 방탈출 「세 그림의 수」

## 실행

설치가 필요 없습니다. `index.html` 하나로 동작하며 Three.js(r128)를 CDN에서 불러옵니다.
GitHub Pages 주소로 접속하거나, 로컬에서는 `python3 -m http.server` 후 브라우저로 열면 됩니다.

## 조작

- PC: W A S D 이동, 화면 클릭 후 마우스로 둘러보기, 클릭 또는 E로 작품 보기, 청자 공간에서 Space/Q로 위아래 이동
- 모바일: 왼쪽 아래 원을 끌어 이동, 화면 오른쪽을 끌어 둘러보기, 작품을 톡 눌러 보기

작품 이미지는 모두 코드로 그린 임시 작품입니다.

## 플랫폼 기능

- 회원가입과 로그인, 내 갤러리(방 이름, 소개, 벽 색, 바닥) 꾸미기
- 작품 이미지 업로드 (JPG/PNG/WebP, 벽에 9점까지), 3D 모델(.glb) 업로드 (좌대에 4개까지)
- 작품 판매 등록, 구매 요청 보내기, 작가의 받은 주문 수락/거절, 구매자의 요청 취소
- 결제는 아직 실제로 처리되지 않습니다 (구매 요청 방식). 실결제는 사업자등록, PG 계약, 통신판매업 신고 후 연결 예정입니다.

### 저장 방식

- `js/config.js`가 비어 있으면 **체험 모드**: 데이터가 그 브라우저(IndexedDB) 안에만 저장되어 다른 사람에게 보이지 않습니다.
- Supabase를 연결하면 모든 방문자가 서로의 갤러리를 볼 수 있습니다.
  1. supabase.com에서 새 프로젝트를 만듭니다 (무료 요금제).
  2. SQL Editor에 `supabase/schema.sql`을 붙여 넣고 Run.
  3. Project Settings > API의 Project URL과 anon public 키를 `js/config.js`에 넣습니다.
