# 작품 속으로 갤러리 (가상 갤러리 플랫폼 프로토타입)

브라우저에서 걸어 다니며 작품을 보고, 작품에서 파생된 3D 공간으로 들어가 보는 가상 갤러리 프로토타입입니다.

- 메인 갤러리 1F 기획전: 호랑이 그림 속 대숲(거대한 호랑이), 청자 매병 안쪽 공간
- 2F 작가 개인전: 작품의 색으로 자동 생성되는 3D 공간
- 3F 입점 작가 모집 (빈 전시실)
- 상설관 방탈출 「세 그림의 수」

## 실행

설치가 필요 없습니다. `index.html` 하나로 동작하며 Three.js(r128)를 CDN에서 불러옵니다.
GitHub Pages 주소로 접속하거나, 로컬에서는 `python3 -m http.server` 후 브라우저로 열면 됩니다.

## 조작

- PC: W A S D 이동, 화면 클릭 후 마우스로 둘러보기, 클릭 또는 E로 작품 보기, 청자 공간에서 Space/Q로 위아래 이동
- 모바일: 왼쪽 아래 원을 끌어 이동, 화면 오른쪽을 끌어 둘러보기, 작품을 톡 눌러 보기

작품 이미지는 모두 코드로 그린 임시 작품입니다.
